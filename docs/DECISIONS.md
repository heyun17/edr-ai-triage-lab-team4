### 저장·하이브리드 검색 결정 (1일차)

- 최종 25개 청크를 OpenSearch의 `kb-playbooks` 인덱스에 저장했다.
- `text`는 BM25 키워드 검색을 위해 `text` 타입으로 저장했다.
- `embedding`은 `text-embedding-3-small`의 1536차원 벡터를 저장하는 `knn_vector`로 구성하고 cosine similarity를 사용했다.
- `source`, `category`는 정확한 값 식별을 위해 `keyword`, `page`, `chunk_index`는 `integer`로 저장했다.
- `text_as_html`은 표 구조 보존용으로 저장하되 검색에는 사용하지 않도록 `index: false`로 설정했다.
- 단일 OpenSearch 노드 환경이므로 replica는 0으로 설정했다.
- 키워드 검색과 벡터 검색의 원래 점수는 척도가 다르므로 직접 합산하지 않고 RRF를 사용했다.
- RRF는 각 검색 결과의 순위에 대해 `1 / (60 + 순위)`를 더하고, 합산 점수가 높은 청크를 최종 상위 결과로 반환하도록 구현했다.
